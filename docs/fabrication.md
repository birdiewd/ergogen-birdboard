# Ordering PCBs (JLCPCB / PCBWay)

Ergogen outputs a KiCad 8 board (`.kicad_pcb`), not Gerbers. The Gerber, drill,
BOM and pick-and-place files the fabs need are exported from KiCad. The
outputs from the web UI: download the PCB for the variant you want (for example
`corne_choc_zero`).

## 1. Prepare the board in KiCad

1. Open the downloaded `.kicad_pcb` in KiCad 8 or newer.
2. Route the traces. Ergogen only places footprints and nets. You can route by
   hand or with the Freerouting plugin (KiCad 8: Tools, External Plugins).
3. Add a ground pour if you want one, then refill zones (press `B`).
4. Run Inspect, Design Rules Checker. Fix every error before ordering.
5. Check the board in the 3D viewer, and check the switch and MCU pads against the
   datasheets (see `docs/footprint-sources.md`).

## 2. Export the fab files

Both fabs accept the same Gerber and drill set.

**Gerbers and drill** (File, Fabrication Outputs, Gerbers; then Drill Files):
- Layers: F.Cu, B.Cu, F.Paste, B.Paste, F.Silkscreen, B.Silkscreen, F.Mask,
  B.Mask, Edge.Cuts.
- Tick "Use Protel filename extensions" only if the fab asks for it. Current
  JLCPCB accepts the default KiCad names.
- Drill: Excellon, "Merge PTH and NPTH holes into one file" unticked, millimeters.
- Zip the Gerbers and the two drill files together.

**Assembly files (BOM and CPL)** are needed only for assembled boards. JLCPCB
recommends the **Fabrication-Toolkit** KiCad plugin (bennymeg). It produces a zip with
Gerbers, BOM and CPL in one step.

## 3. Known gaps

- **Hotswap sockets are not in the BOM.** The footprint draws the socket pads
  but is not tied to a part, so the plugin leaves the sockets out of the BOM
  (ceoloide/ergogen-footprints issue #58). Add them to the BOM by hand. The
  Kailh Choc hotswap socket `CPG135001S30` is LCSC `C5333465` according to that issue.
  Check the part number on LCSC before ordering.
- **Every key has two LED footprints (front and back); only one set is ever populated.**
  Left half: front set. Right half: the same PCB flipped, so the back set. If you order
  assembly, delete the unused set from the BOM and CPL (or the board will be built with
  both), and order the left and right halves as two separate assembly jobs.
- **1N4148 through-hole diodes are hand-soldered** (or use JLCPCB's through-hole assembly if you
  order it). If you only want SMD parts assembled, leave the diodes out of the BOM and CPL.
- **Footprints have no LCSC part numbers** (diodes, LEDs, MCU headers). Add an
  `LCSC` field per component in KiCad, or edit the BOM before upload.
- **Rotation offsets.** JLCPCB's placement preview often shows 90 or 180 degree
  errors on SMD diodes and LEDs. Correct them on the order page preview.
- **Reversible boards.** Components placed on the back need B.Paste and the
  correct side in the CPL. Check the preview.
- **Only the left half is generated.** For a split keyboard, order one
  design and flip the board for the other half, or ask the fab for a quantity of 2
  and mount parts on opposite sides.

## 4. Ordering

**JLCPCB:** upload the Gerber zip, choose thickness (1.2 mm for Choc hotswap
sockets, 1.6 mm is fine for MX), pick the surface finish and colour, and choose
Assembly only if you want parts placed. Upload the BOM and CPL at the assembly step.

**PCBWay:** upload the same Gerber zip. For assembly, upload the BOM and CPL
as "Assembly files".

## Checklist before paying

- [ ] DRC clean
- [ ] Board outline closed on Edge.Cuts
- [ ] Mounting holes present (not generated by default in this repo)
- [ ] BOM includes hotswap sockets, diodes, LEDs
- [ ] Fab preview shows part rotations correctly
